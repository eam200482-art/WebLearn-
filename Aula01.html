Introdução ao HTML

HTML é a linguagem de marcação padrão usada para estruturar e organizar o conteúdo de páginas na web.

1. As três tecnologias básicas da Web

Para criar uma página web básica, normalmente utilizamos três tecnologias principais:

1.1. HTML (HyperText Mark Language)

É uma linguagem de marcação usada para estruturar o conteúdo de uma página web.

Com HTML podemos definir:

  • Títulos;
  • Parágrafos;
  • Imagens;
  • Links;
  • Listas;
  • Formulários;
  • Tabelas;
  • etc.

Importante: HTML não é uma linguagem de programação.

1.1.2. CSS (Cascading Style Sheets)

É usado para estilizar e organizar visualmente a página, ou seja, cuida principalmente da aparência da página.

Com CSS podemos definir:

  • Cores;
  • Tamanhos;
  • Fontes;
  • Espaçamentos;
  • Posições;
  • Bordas;
  • Layouts;
  • Animações;
  • etc.

1.3. JS (JavaScript)

É uma linguagem de programação usada para adicionar comportamento e interatividade às páginas web.

JavaScript pode fazer:

  • Um botão responder ao clique;
  • Validar um formulár;
  • Mostrar ou esconder conteúdo;
  • Realizar cálculos;
  • etc.


2. Uma forma simples de memorizar

Imagine um corpo humano:



  1. HTML: estrutura (esqueleto)
  2. CSS: aparência (roupa)
  3. JavaScript: comportamento (acções)


3. Criar uma página HTML

PRIMEIRO: Criar uma pasta

Crie uma pasta para guardar os arquivos do projeto.

Exemplo:
Pasta chamado MeuSite

SEGUNDO: Criar o arquivo HTML

Dentro da pasta, crie um arquivo. Pode dar, por exemplo, o nome de index.html.
Esse arquivo será a página principal do site.

Importante: No caso geral, o nome do arquivo tem de ser sempre seguida pelo nome da linguagem (html, css ou js), para especificar a linguagem que está em uso no arquivo.

TERCEIRO: Escrever o código HTML

Abra o arquivo index.html no editor de código e faça a estrutura HTML do teu site.



4. Tags fundamentais da estrutura do HTML

Tag: é uma marcação usada para identificar ou delimitar determinados elementos no HTML. Isto é, é a declaração do tipo de documento. 

<!DOCTYPE html>
Document type declaration (declaração do tipo de documento da linguagem htm), essa linha informa ao navegador que o documento utiliza o padrão HTML5. 

<html>
 A tag que representa o documento HTML como um todo. Geralmente, todo o conteúdo da página fica dentro de <html>.

O HTML inclui 3 (três) tags fundamentais na sua estrutura, aqui estão:

4.1. Cabeçalho (head)

Contém informações e configurações da página que, em geral, não aparecem diretamente como conteúdo da página para o usuário.

Dentro do <head> podemos colocar informações como:

  • Título da página;
  • Codificação de caracteres;
  • Configurações para dispositivos móveis;
  • Links para arquivos CSS;
  • etc.

4.2. Corpo (body)

Contém o conteúdo principal da página, aquilo que o usuário normalmente vê no navegador.

4.3. Pé (footer)

Representa o rodapé de uma página ou de uma determinada seção.

Exemplo: 


      <p>© 2026 Meu Site.</p>


Importante: o <footer> não faz parte da estrutura obrigatória head + body. Ele é um elemento de conteúdo que normalmente fica dentro do body.

4.4. A relação entre <ol>, <ul> e <li>

Entenda através da seguinte analogia, pense assim:

  • <ol> ou <ul> = o recipiente da lista.

  • <li> = cada elemento dentro desse recipiente.
