Idioma da página e meta tags

1. Definindo o idioma da página

Para informar ao navegador qual é o idioma principal do conteúdo da página, usamos o atributo lang dentro da tag <html>.

Exemplo: 

<html lang="pt-MZ">

Importante: lang não é uma tag. Mas sim, um atributo da tag <html>.



2. Meta Tags

As meta tags fornecem informações sobre a página para o navegador, mecanismos de pesquisa e outros sistemas.

Elas são colocadas dentro da tag <head>.

2.1 <meta charset="UTF-8">

Define a codificação dos caracteres utilizados na página, isto é, diz ao navegador como interpretar os caracteres do texto da página.

Isso permite que caracteres como: á, é, í, ó, ú, ã, õ, ç sejam apresentados corretamente.

2.2 <meta name="viewport">

É muito importante para páginas que serão visualizadas em celulares, tablets e computadores. Ajuda a página a funcionar em diferente tamanhos da tela.

Linha completa: 

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Significados:

  • width=device-width: faz a largura da página acompanhar a largura do dispositivo.

  • initial-scale=1.0: define a escala inicial da página como 1, ou seja, sem zoom inicial.

Atenção: Essa meta tag ajuda na adaptação da página, mas sozinha não torna o site totalmente responsivo. O CSS também é necessário.

2.3 <meta name="description">

É usada para fornecer uma descrição da página.

Exemplo:

<meta name="description" content="Site para aprender HTML, CSS e JavaScript.">

A informação da descrição pode ser utilizada pelos mecanismos de pesquisa, como o Google, em seus resultados.

2.4 <meta name="author">

Indica quem é o autor ou responsável pelo conteúdo da página.

Exemplo: 

<meta name="author" content="Elton Mandlhaze">


Estrutura básica de tudo que aprendemos nesta aula

<!DOCTYPE html>
<html lang="pt-MZ">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Site para aprender HTML, CSS e JavaScript.">
    <meta name="author" content="Elton Mandlhaze">
    <title>Aprendendo HTML</title>
  </head>
</html>
