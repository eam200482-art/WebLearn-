Comentários, Links e Imagens

1. Comentários em HTML

Os comentários são textos escritos no código que não aparecem na página para o usuário.

Eles servem principalmente para explicar o código, organizar partes da página ou deixar uma observação para uma futura alteração.

Exemplo:

<h1>WebLearn</h1>
   <!-- Este parágrafo apresenta o site -->
   <p>Aprenda HTML de forma simples.</p>

No navegador, aparecerá apenas:
WebLearn
Aprenda HTML de forma simples.

Pequenos detalhes

Podemos usar comentários para:

  • Explicar o código;
  • Separar partes do código;
  • Deixar lembretes;
  • Facilitar a manutenção do projeto.

Nota: Comentários são para quem está trabalhando no código. Eles não são mostrados normalmente na página.



2. Link

É um elemento que permite ao usuário clicar e ser levado para outro lugar.

Podemos criar links para:

  • Outro site;
  • Outra página do nosso projeto;
  • Uma página de um curso;
  • Um vídeo;
  • etc

Para criar um link, a tag principal usada é: <a></a>.

Mas precisamos informar para onde o link deve levar. Para isso, usamos o atributo href.

Exemplo:

<a href="https://www.youtube.com/">Visitar YouTube</a>

Entenda o código

  • <a></a>: cria o link.
  • href: indica para onde o link deve levar.
  • https://www.youtube.com/: é o endereço para onde o usuário será levado.
  • Visitar YouTube: é o texto que aparece na página.

Nota: Cria-se também link para outra página do nosso próprio site.



3. Imagem

É um recurso visual que podemos colocar dentro da nossa página.

Podemos usar imagens para:

  • Ilustrar um conteúdo;
  • Mostrar exemplos;
  • Apresentar um produto;
  • Colocar um logotipo;
  • Tornar a página mais visual.

Para a colacação de uma imagem numa página usa-se a tag: <img>

Mas para essa tag funcionar corretamente precisamos informar onde encontrar a imagem, para isso usamos o atributo src.

Exemplo:

<img src="imagem.jpg" alt="Uma imagem de exemplo">

Entenda o código

  • <img>: indica que queremos colocar uma imagem.
  • src: informa onde está a imagem.
  • imagem.jpg: é o nome do arquivo da imagem.
  • alt: fornece uma descrição da imagem.
