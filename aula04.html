Elementos de citação e referência

Objetivo da aula

Aprender a usar algumas tags HTML para indicar informações, referências, obras e textos que foram retirados ou mencionados de outras fontes.

1. <abbr title="..."> (Abreviações)

Usada para indicar que uma palavra ou expressão é uma abreviação.

O atributo title pode mostrar o significado completo quando o usuário passa o cursor sobre a abreviação.



2. <address> (Informações de contacto)

Usada para indicar informações de contacto do autor de uma página ou de uma obra.

Pode conter, por exemplo:

  • nome;
  • e-mail;
  • telefone;
  • endereço físico;
  • link para contacto.


3. <cite> (Título de uma obra)

Usada para indicar o título de uma obra, como:

  • livro;
  • filme;
  • música;
  • pintura;
  • artigo;
  • peça de teatro.


4. <q> (Citação curta)

Usada para indicar uma citação curta dentro de uma frase.

Normalmente, o navegador coloca aspas automaticamente.



5. <blockquote> (Citação longa)

É usada para indicar uma citação mais longa, geralmente um trecho retirado de outra fonte.
